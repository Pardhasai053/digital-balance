Digital Balance - Responsive Web Prototype

Open index.html in a modern browser.

Updated features:
- Login fields use standard browser/password-manager autocomplete attributes so saved email/password suggestions can appear.
- Create Account is connected to a working local prototype flow.
- After login or account creation, the user chooses one of three personas: Academic Achiever, Gaming & Entertainment Student, or Faculty.
- Digital Fatigue Check now recalculates the fatigue level and percentage from selected symptoms.
- The fatigue level buttons also update the matching symptom selections for quick testing.
- Responsive layouts are included for mobile, tablet and desktop aspect ratios.
- No backend or real authentication/database is included; this is a front-end prototype.
